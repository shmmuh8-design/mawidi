# موعدي
حجز المواعيد في عُمان: الحلاق، الصالون، العيادة، الورشة… الزبون يحجز، والمحل يدير حجوزاته.
- قاعدة البيانات: `supabase/setup.sql` (الصقه في Supabase ← SQL Editor ← Run)
- المفتاح في `config.js` عام (publishable) فقط.

## لوحة الإدارة
- شغّل `supabase/admin.sql` في Supabase ← SQL Editor (بعد setup.sql).
- حدّد رمز الإدارة بنفسك بالسطر الأخير في الملف (لا ترسله لأحد).
- افتح `admin.html` — تفعيل الاشتراكات (+شهر/٣ أشهر/سنة)، أيام مجانية، إيقاف محل، رسالة تجديد بالواتساب، والبلاغات.
- ٥ محاولات خاطئة = قفل ١٥ دقيقة.
